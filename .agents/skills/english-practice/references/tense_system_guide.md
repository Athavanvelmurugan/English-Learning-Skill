# Tense System Master Guide

This guide details all 12 English tenses, providing structures, positive/negative/question forms, Tamil hints, signal words, common errors, and workplace examples for the English Practice Skill.

---

# Tense Matrix Overview

| Tense Name | Structure (Positive) | Meaning / Tamil Hint | Workplace Example |
| :--- | :--- | :--- | :--- |
| **1. Simple Present** | `S + base verb (-s/-es)` | Habits/Routines (வழக்கமான செயல்) | We deploy code every Friday. |
| **2. Present Continuous** | `S + am/is/are + verb-ing` | Happening now (இப்போது நடக்கிறது) | I am testing the API endpoint. |
| **3. Simple Past** | `S + past verb (V2)` | Finished past (முடிந்த செயல்) | I fixed the bug yesterday. |
| **4. Past Continuous** | `S + was/were + verb-ing` | In progress in past (கடந்த கால தொடர்) | I was debugging when the server dropped. |
| **5. Simple Future** | `S + will + base verb` | Future action (எதிர்கால செயல்) | We will release the update tomorrow. |
| **6. Future with going to** | `S + am/is/are + going to + V1` | Planned future (திட்டமிட்ட எதிர்காலம்) | We are going to migrate the DB next week. |
| **7. Present Perfect** | `S + have/has + past participle (V3)` | Past action with present relevance | I have merged the pull request. |
| **8. Present Perfect Continuous**| `S + have/has + been + verb-ing` | Started in past, still continuing | I have been investigating this issue for 2 hours. |
| **9. Past Perfect** | `S + had + past participle (V3)` | Action completed before another past action | The client had left before we started the demo. |
| **10. Past Perfect Continuous** | `S + had + been + verb-ing` | Ongoing action before past moment | We had been testing for days before finding the bug. |
| **11. Future Perfect** | `S + will + have + V3` | Action finished before future time | I will have completed the task by 5 PM. |
| **12. Future Perfect Continuous**| `S + will + have + been + verb-ing` | Duration up to a future point | By December, I will have been working here for 2 years. |

# Detailed Tense Cards

## 1. Simple Present
- **Structure:**
  - Positive: `Subject + base verb` (`He/She/It + verb-s/es`)
  - Negative: `Subject + do/does not + base verb`
  - Question: `Do/Does + subject + base verb?`
- **Signal Words:** `every day`, `usually`, `always`, `often`, `normally`
- **Common Error:** ❌ `She work in Chennai.` → ✅ `She works in Chennai.`

## 2. Present Continuous
- **Structure:**
  - Positive: `Subject + am/is/are + verb-ing`
  - Negative: `Subject + am/is/are not + verb-ing`
  - Question: `Am/Is/Are + subject + verb-ing?`
- **Signal Words:** `now`, `currently`, `at the moment`, `today`
- **Common Error:** ❌ `We currently using Playwright.` → ✅ `We are currently using Playwright.`

## 3. Simple Past
- **Structure:**
  - Positive: `Subject + past verb (V2)`
  - Negative: `Subject + did not + base verb (V1)`
  - Question: `Did + subject + base verb (V1)?`
- **Signal Words:** `yesterday`, `last week`, `in 2025`, `ago`
- **Common Error:** ❌ `I did not completed the task.` → ✅ `I did not complete the task.`

## 4. Present Perfect vs Simple Past
- **Simple Past:** Specific finished time in the past (`yesterday`, `last night`).
  - Example: *I submitted the report yesterday.*
- **Present Perfect:** Unspecified past time or action with impact on now.
  - Example: *I have submitted the report.* (It is ready now).
- **Common Error:** ❌ `I have completed the task yesterday.` → ✅ `I completed the task yesterday.`
